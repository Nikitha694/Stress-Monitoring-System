# 🧠 Stress Monitoring & Assistance System

An AI-powered Stress Monitoring & Assistance System that predicts a user's stress level using Machine Learning based on lifestyle, health, and daily routine factors. The application provides personalized recommendations to help users improve their mental well-being.

---

## 📌 Features

- 🔍 Stress level prediction using a trained Machine Learning model
- 📊 Interactive dashboard
- 📝 Weekly stress reports
- 💡 Personalized recommendations
- 🎮 Stress-relief games
- 🧘 Interactive wellness hub
- 📱 Responsive and modern user interface
- ⚡ Real-time prediction using Flask API

# ⚙ Installation Guide

## Step 1: Clone the Repository

```bash
git clone https://github.com/Nikitha694/Stress-Monitoring-System.git
```

Go to the project folder:

```bash
cd Stress-Monitoring-System
```

---

# Backend Setup

Open a terminal.

Navigate to the backend folder.

```bash
cd backend
```

Install required Python libraries.

```bash
pip install -r requirements.txt
```

Move to the website folder.

```bash
cd website
```

Run the Flask server.

```bash
python app.py
```

The backend will start at

```
http://127.0.0.1:5000
```

Leave this terminal running.

---

# Frontend Setup

Open another terminal.

Navigate to the frontend folder.

```bash
cd frontend
```

Install all required Node packages.

```bash
npm install
```

Run the React application.

```bash
npm run dev
```

The frontend will start at

```
http://localhost:5173
```

Open the above URL in your browser.

## 🚀 How to Use

1. Open the application.
2. Navigate to the **Prediction** page.
3. Enter your lifestyle and health information.
4. Click **Predict My Stress Level**.
5. View your predicted stress level.
6. Explore recommendations, dashboard, reports, and wellness features.
